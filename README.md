# LactateLab

Modern React + TypeScript dashboard for analyzing progressive running lactate tests.

## Features

- Editable lactate test table with automatic speed, pace, and duration conversion.
- Multiple lactate threshold methods: fixed 2/4 mmol, Dmax, modified Dmax, baseline + 1.0 mmol/L, and log-log segmentation.
- Dynamic training zones, interval target times, estimated race paces, data quality warnings, and advice.
- Recharts visualizations for lactate, heart rate, combined response, and zone ranges.
- JSON, CSV, clipboard, and print export options.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```
